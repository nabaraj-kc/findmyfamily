<task id="4.1">
<title>Create Button component</title>
<read_first>
- src/styles/tokens.css (design tokens for colors, spacing, radius, shadows)
- DESIGN_SYSTEM.md (button variants, tone of voice)
</read_first>
<action>
Create `src/components/atoms/Button/Button.tsx` and `src/components/atoms/Button/Button.module.css`.

Button variants:
- **primary**: Accent-500 background, white text — main CTAs ("Send this report")
- **secondary**: Slate-100 background, slate-700 text — secondary actions
- **warm**: A warm variant with accent-50 background, accent-700 text — emotionally important actions
- **ghost**: Transparent, slate-600 text — tertiary/subtle actions
- **danger**: Error-colored — destructive actions (used rarely)

Sizes: `sm` (32px height, text-sm), `md` (40px height, text-base), `lg` (48px height, text-lg)

Props interface:
```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'warm' | 'ghost' | 'danger';
  size?: 'sm' | 'md' | 'lg';
  fullWidth?: boolean;
  loading?: boolean;
  icon?: React.ReactNode;
  iconPosition?: 'left' | 'right';
}
```

CSS must use design tokens exclusively (no hardcoded colors). Include:
- Hover states with subtle color shift
- Active/pressed state
- Focus-visible outline using --color-focus-ring
- Disabled state (reduced opacity, no pointer events)
- Loading state (spinner replaces icon, reduced opacity)
- Smooth transitions using --duration-fast and --ease-default
- Mobile touch-friendly minimum 44px tap target

Button.module.css should NOT exceed 120 lines. Keep it tight using CSS custom properties for variant overrides.
</action>

- Button.tsx exports `Button` as default or named export

- Button.tsx contains `loading` prop
- Button.module.css contains `var(--color-accent-500)` for primary variant
- Button.module.css contains `var(--color-focus-ring)` for focus state
- Button.module.css contains `min-height` or equivalent ensuring 44px touch target
</acceptance_criteria>
</task>

Props interface:
```typescript
interface InputProps extends React.InputHTMLAttributes<HTMLInputElement> {
  label?: string;
  error?: string;
  helperText?: string;
  icon?: React.ReactNode;
  showVoiceInput?: boolean;
  fullWidth?: boolean;
}
```

Also create a TextArea variant in the same file:
```typescript
interface TextAreaProps extends React.TextareaHTMLAttributes<HTMLTextAreaElement> {
  label?: string;
  error?: string;
  helperText?: string;
  showVoiceInput?: boolean;
  fullWidth?: boolean;
}
```

CSS requirements:
- Surface-50 background with slate-200 border, slate-300 on hover, accent-400 on focus
- Error state: error-colored border and helper text
- Label positioned above input, text-sm, slate-600
- Helper text below input, text-xs, slate-400 (or error color)
- Voice input button scaffolded as a small microphone icon button inside the input (right side)
- Generous padding for Devanagari text (extra vertical padding vs Latin — use `[lang="ne"]` selector to add 2px)
- 44px minimum height for touch targets
- Full-width by default on mobile

<title>Create Icon wrapper, Spinner, and ProgressBar components</title>
<read_first>
- src/styles/tokens.css
- DESIGN_SYSTEM.md (iconography, motion)
</read_first>
<action>
Create three small components:

**1. Icon wrapper** (`src/components/atoms/Icon/Icon.tsx`):
```typescript
interface IconProps {
  name: string; // Lucide icon name
  size?: number;
  color?: string;
  strokeWidth?: number;
  className?: string;
  'aria-label'?: string;
}
```
A thin wrapper around Lucide's dynamic import pattern. Default size 20px, strokeWidth 1.5, color currentColor. Includes `aria-hidden="true"` by default unless `aria-label` is provided.

**2. Spinner** (`src/components/atoms/Spinner/Spinner.tsx` + `.module.css`):
Simple rotating circle animation. Sizes: sm (16px), md (24px), lg (32px). Uses `--color-accent-500` with a lighter track. Respects `prefers-reduced-motion`.

**3. ProgressBar** (`src/components/atoms/ProgressBar/ProgressBar.tsx` + `.module.css`):
Two variants:
- **bar**: Horizontal progress bar with percentage fill (for general progress)
- **dots**: Step indicator dots (for multi-step forms) — numbered circles connected by lines, current step highlighted

Props for dots variant:
```typescript
interface ProgressDotsProps {
  totalSteps: number;
  currentStep: number;
  labels?: string[];
}
```

ProgressBar uses `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` for accessibility.
</action>
