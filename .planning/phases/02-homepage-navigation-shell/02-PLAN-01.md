# Plan 1: Header & Footer Organisms

**Goal**: Build the persistent navigation shell (Header and Footer) and integrate it into the root locale layout.

**Tasks**:
1.1 Create `src/context/PreferencesContext.tsx` to manage Data Saver state.
1.2 Create `src/components/organisms/Header/Header.tsx` and `Header.module.css`.
  - Include Logo, Navigation Links, `LanguageToggle`, and a `DataSaverToggle` button.
  - Implement mobile hamburger menu and sticky glassmorphism styling.
1.3 Create `src/components/organisms/Footer/Footer.tsx` and `Footer.module.css`.
  - Include Emergency Hotlines (reading from `src/constants/emergency.ts`).
  - Include basic links (About, Privacy, Contact).
1.4 Update `src/app/[locale]/layout.tsx` to wrap `children` with `<PreferencesProvider>`, `<Header>`, and `<Footer>`.
