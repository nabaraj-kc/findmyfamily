FormField composes an Input/TextArea with a label, optional helper text, error message, and optional character count. It's the standard way to include form inputs across the app.

```typescript
interface FormFieldProps {
  label: string;
  name: string;
  type?: 'text' | 'tel' | 'email' | 'number' | 'textarea';
  required?: boolean;
  error?: string;
  helperText?: string;
  placeholder?: string;
  value?: string;
  onChange?: (e: React.ChangeEvent<HTMLInputElement | HTMLTextAreaElement>) => void;
  showVoiceInput?: boolean;
  maxLength?: number;
  icon?: React.ReactNode;
}
```

CSS: Stack label above input with `--space-1` gap. Error text in `--color-error`. Helper text in `--color-text-muted`. Required fields show a subtle warm accent dot (not a screaming red asterisk).
