**Typography:**
- Latin: Noto Sans (400, 500, 600, 700) via next/font
- Devanagari: Noto Sans Devanagari (400, 500, 600, 700) via next/font
- Type scale (rem-based, 16px root):
  ```
  --text-xs:    0.75rem / 1rem      (12px — captions, fine print)
  --text-sm:    0.875rem / 1.25rem  (14px — secondary text, labels)
  --text-base:  1rem / 1.5rem       (16px — body text)
  --text-lg:    1.125rem / 1.75rem  (18px — emphasized body)
  --text-xl:    1.25rem / 1.75rem   (20px — card titles)
  --text-2xl:   1.5rem / 2rem       (24px — section headings)
  --text-3xl:   1.875rem / 2.25rem  (30px — page titles)
  --text-4xl:   2.25rem / 2.5rem    (36px — hero headings)
  --text-5xl:   3rem / 1.1          (48px — display, used sparingly)
  ```

<action>
Create `src/styles/tokens.css` with ALL design tokens as CSS custom properties.

Structure the file in this order:
1. `:root` block with primitive color tokens (slate-50 through slate-900, surface-50 through surface-900, accent-50 through accent-900)
2. Semantic color tokens (--color-bg-primary, --color-bg-secondary, --color-text-primary, --color-text-secondary, --color-text-muted, --color-border, --color-focus-ring, --color-cta, --color-cta-hover, --color-success, --color-warning, --color-error, --color-info)
3. Spacing tokens (--space-0.5 through --space-24)
4. Typography tokens (--text-xs through --text-5xl with font-size and line-height pairs)
5. Font family tokens (--font-latin, --font-devanagari, --font-body, --font-heading)
6. Font weight tokens (--weight-normal: 400, --weight-medium: 500, --weight-semibold: 600, --weight-bold: 700)
7. Border radius tokens
8. Shadow/elevation tokens
9. Transition/motion tokens
10. Z-index scale (--z-dropdown: 50, --z-sticky: 100, --z-modal: 200, --z-toast: 300, --z-tooltip: 400)
11. Breakpoint reference comments (not usable as custom properties but documented: sm: 640px, md: 768px, lg: 1024px, xl: 1200px)

Use the exact HSL values from DESIGN_SYSTEM.md. The semantic tokens should map to primitives:
```css
--color-bg-primary: var(--color-surface-50);
--color-bg-secondary: var(--color-surface-100);
--color-text-primary: var(--color-slate-800);
--color-text-secondary: var(--color-slate-600);
--color-text-muted: var(--color-slate-400);
--color-border: var(--color-slate-200);
--color-focus-ring: var(--color-accent-400);
--color-cta: var(--color-accent-500);
--color-cta-hover: var(--color-accent-600);
```

Also add a `[data-theme="high-contrast"]` block that overrides semantic tokens for high-contrast mode:
```css
[data-theme="high-contrast"] {
  --color-bg-primary: #ffffff;
  --color-text-primary: #000000;
  --color-text-secondary: #1a1a1a;
  --color-border: #333333;
  /* etc. */
}
```

/* Modern CSS Reset — adapted for Find My Family */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

html {
  -moz-text-size-adjust: none;
  -webkit-text-size-adjust: none;
  text-size-adjust: none;
  scroll-behavior: smooth;
}

body {
  min-height: 100vh;
  min-height: 100dvh;
}

img, picture, video, canvas, svg {
  display: block;
  max-width: 100%;
  height: auto;
}

input, button, textarea, select {
  font: inherit;
  color: inherit;
}

button {
  cursor: pointer;
  border: none;
  background: none;
}

a {
  color: inherit;
  text-decoration: none;
}

ul, ol {
  list-style: none;
}

p, h1, h2, h3, h4, h5, h6 {
  overflow-wrap: break-word;
}

/* Reduced motion preference */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* Focus styles for keyboard navigation */
:focus-visible {
  outline: 2px solid var(--color-focus-ring);
  outline-offset: 2px;

  outline: none;
}
