<objective>
Set up the complete bilingual infrastructure using next-intl so that every subsequent component and page can render in both Nepali (Devanagari) and English with a single `t('key')` call. Default to Nepali for Nepal-geolocated users, English otherwise.
</objective>

<task id="3.1">
<title>Configure next-intl routing and middleware</title>
<read_first>
- package.json (verify next-intl is installed)
- src/app/layout.tsx (current layout structure)
- next.config.ts
</read_first>
<action>
Create the next-intl configuration files:

1. Create `src/i18n/routing.ts`:
```typescript
import { defineRouting } from 'next-intl/routing';

export const routing = defineRouting({
  locales: ['ne', 'en'],
  defaultLocale: 'ne',
  localePrefix: 'as-needed', // Only show /en/ prefix for non-default locale
});
```

2. Create `src/i18n/request.ts`:
```typescript
import { getRequestConfig } from 'next-intl/server';
import { routing } from './routing';

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale;
  
  if (!locale || !routing.locales.includes(locale as any)) {
    locale = routing.defaultLocale;
  }

  return {
    locale,
    messages: (await import(`./messages/${locale}.json`)).default,
  };
});
```

3. Create `src/middleware.ts`:
```typescript
import createMiddleware from 'next-intl/middleware';
import { routing } from './i18n/routing';

export default createMiddleware(routing);

export const config = {
  matcher: ['/', '/(ne|en)/:path*'],
};
```

4. Update `next.config.ts` to add the next-intl plugin:
```typescript
import createNextIntlPlugin from 'next-intl/plugin';

const withNextIntl = createNextIntlPlugin('./src/i18n/request.ts');

// ... existing config ...

export default withNextIntl(nextConfig);
```
</action>

- File `next.config.ts` contains `createNextIntlPlugin`
</acceptance_criteria>

<title>Restructure app directory for locale routing</title>
<read_first>

</read_first>
<action>
next-intl with App Router requires locale-based routing. Restructure:

1. Move `src/app/layout.tsx` content into `src/app/[locale]/layout.tsx` — this becomes the locale-aware root layout
2. Move `src/app/page.tsx` into `src/app/[locale]/page.tsx`
3. Keep `src/app/layout.tsx` as a minimal shell (just html/body tags, no locale logic) OR use `src/app/[locale]/layout.tsx` as the primary layout with next-intl's `NextIntlClientProvider`

The locale layout should:
```typescript
import { NextIntlClientProvider } from 'next-intl';
import { getMessages, getTranslations } from 'next-intl/server';
import { notFound } from 'next/navigation';
import { routing } from '@/i18n/routing';

export default async function LocaleLayout({
  children,
  params,
}: {
  children: React.ReactNode;
  params: Promise<{ locale: string }>;
}) {
  const { locale } = await params;
  
  if (!routing.locales.includes(locale as any)) {
    notFound();
  }

  const messages = await getMessages();

  return (
    <NextIntlClientProvider messages={messages}>
      {children}
    </NextIntlClientProvider>
  );
}
```

The root layout (`src/app/layout.tsx`) should wrap everything with fonts and globals:
```typescript
import { Noto_Sans, Noto_Sans_Devanagari } from 'next/font/google';
import '@/styles/globals.css';

// ... font setup ...

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html className={`${notoSans.variable} ${notoSansDevanagari.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

Create a simple placeholder page at `src/app/[locale]/page.tsx`:
```typescript
import { useTranslations } from 'next-intl';

export default function HomePage() {
  const t = useTranslations('common');
  return (
    <main>
      <h1>{t('appName')}</h1>
      <p>{t('tagline')}</p>
    </main>
  );
}
```
